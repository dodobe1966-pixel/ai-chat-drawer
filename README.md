# AI 대화서랍 · AI Chat Drawer

ChatGPT, Claude, Claude Code, Codex, Gemini 에서 나눈 대화를 내 컴퓨터 한곳에 모아 날짜와 프로젝트로 다시 찾는 무료 앱입니다. 대화는 내 컴퓨터 밖으로 나가지 않습니다.

A free app that gathers your ChatGPT, Claude, Claude Code, Codex and Gemini chats in one place on your own computer, so you can find them again by date and by project. Your chats never leave your computer.

## 시작하기

**Windows** — ZIP 을 통째로 압축 풀고 `실행.bat` 을 더블클릭합니다. 설치할 것은 없습니다(파이썬이 들어 있습니다). 처음 받을 때 「자주 다운로드되지 않는 파일」 경고가 뜨면 [자세히] → [실행] 을 누르세요.

**Mac** — ZIP 을 풀고 `AI대화서랍_시작.command` 를 더블클릭합니다. 막히면 시스템 설정 → 개인정보 보호 및 보안 → 「그래도 열기」. Mac 에 들어 있는 파이썬 3 으로 돌아갑니다.

자세한 사용법은 압축을 푼 폴더의 `guide.html` 에 있습니다.

## Getting started

**Windows** — Extract the whole ZIP and double-click `Start.bat`. Nothing to install (Python is included). If a "not commonly downloaded" warning appears, choose More info › Run anyway.

**Mac** — Extract the ZIP and double-click `Start_AI_Chat_Drawer.command`. If macOS blocks it: System Settings › Privacy & Security › Open Anyway. It runs on the Python 3 that comes with your Mac.

See `guide.html` in the extracted folder for full instructions.
