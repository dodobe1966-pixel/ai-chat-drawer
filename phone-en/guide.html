AI Chat Drawer on your phone

Keep your AI chats together on one phone

1Add it to your home screen

iPhone (Safari)

  1. Open the AI Chat Drawer address in Safari. (It has to be Safari, not Chrome.)
  2. Tap the Share button (a square with an arrow pointing up) at the bottom.
  3. Scroll down, tap Add to Home Screen, then tap Add at the top right.
  4. Open it from the new AI Chat Drawer icon and it runs full screen like an app.

Android (Chrome)

  1. Open the AI Chat Drawer address in Chrome.
  2. Tap the three-dot menu at the top right.
  3. Tap Install app, or Add to Home screen if you don't see it.
  4. Open it from the AI Chat Drawer icon on your home screen or app drawer.

Once opened, it also works without internet. The address has to start with https to install.

2Adding chats

Tap Add chat at the top right, then Import file, and choose an exported file. Check the chats it found, then save. You can choose a ZIP as it is, without unzipping.

ChatGPT
  1. In ChatGPT, go to Settings → Data controls → Export data.
  2. Download the ZIP from the link in the email. (It goes to the Files app or Downloads.)
  3. In the drawer, tap Add chat → Import file and choose that ZIP.
Claude (claude.ai)
  1. On claude.ai, go to Settings → Privacy → Export data.
  2. Download the ZIP file from the link in the email.
  3. Use Import file to choose that ZIP.
Gemini
  1. Go to Google Takeout.
  2. Tap Deselect all, tick only My Activity, and inside it keep only Gemini Apps.
  3. Choose the ZIP you get with Import file, as it is.
Other AIs and copied text
  1. In the chat, long-press the text and copy it.
  2. Paste it into Add chat → Paste a conversation, type a title and save.
  3. JSON, JSONL, TXT, MD and HTML files also work with Import file.

The email can take from a few minutes to a day. Menu names may change a little when the services update.

3Linking with your home PC

Link the phone with AI Chat Drawer on your PC, and chats gathered on the PC come to the phone while chats you add or edit on the phone go to the PC. There are two ways.

Way 1. Sync automatically (when your PC has an outside address)

  1. Keep AI Chat Drawer running on the PC. The PC has to be on to sync.
  2. On the phone, open the PC’s outside address followed by /phone/ (for example https://your-address/phone/).
  3. Enter the entry password once. It’s in password.txt in the PC app folder. It won’t ask again for 30 days.
  4. Add that page to your home screen as in step 1. This icon is now the drawer linked to your home PC.
  5. It syncs every time you open the app. To sync right away, tap Sync with PC at the bottom of the left menu.
What gets synced? Chats you add on the phone, edited titles, projects and favorites, and deleted chats (kept 3 days in the PC trash) go to the PC, and every chat on the PC comes to the phone. While the PC is off, the phone shows what it already has and syncs the next time the PC is on.

On a Mac or any other computer, open the same address in Safari or Chrome to use the same drawer. In Mac Safari, File → Add to Dock keeps it like an app.

To open an outside address, create outside_address.txt in the PC app folder and write one HTTPS address on a line (such as a Cloudflare Tunnel). Without one, use way 2.

Way 2. Move a backup file (works anywhere)

  1. On the PC version, gather chats with Find chats on this PC, then save a file with Export backup at the bottom left.
  2. Send that file to your phone (email, a messenger, Google Drive, iCloud and so on).
  3. In the phone drawer, choose it with Add chat → Import file. The same chat never goes in twice.
  4. To send phone chats to the PC, do the reverse: Export backup on the phone, then Add chat → Import file on the PC.

4Saved on this phone only, so back up

Your chats are saved only inside this phone's browser. Unless you link it with your home PC, they are never sent anywhere. (When opened from the public web address, only an anonymous open count is kept on GitHub. No chats, names or contacts are sent.) If you change phones, remove the app, or clear the browser's history and site data, the chats go too. On iPhone, the browser may also clear storage for sites you haven't opened in a long time.
  1. On days you add chats, tap Export backup in the left menu to save one file.
  2. Move that file somewhere that lives outside the phone too, such as Google Drive or iCloud.
  3. To bring everything back, choose that backup file with Import file.

Deleted chats can be restored from the Trash for 3 days.

5Troubleshooting

I can't find Add to Home Screen on iPhone

Make sure you opened it in Safari. It doesn't show inside other apps' built-in browsers. Tap Open in Safari first.

It says no chats were found

Check that it's an export file with chats in it. For ChatGPT it's the ZIP with conversations.json; for Gemini it's the My Activity ZIP. A very large ZIP can be too much for phone memory. If so, add it on the PC version and bring it over as a backup file.

I got a new phone

Tap Export backup on the old phone and Import file on the new one.
